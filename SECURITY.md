# Security policy

## Reporting a vulnerability

Report package vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/bvdcode/nissan-connect-sdk/security/advisories/new).
Do not open a public issue for a vulnerability that could expose account or vehicle access.

Include the affected version, impact, reproduction steps, and a minimal test case when
available. Do not include credentials, OAuth tokens, vehicle identifiers, or customer data.

## Supported versions

Security fixes are released for the latest minor version of `pynissan`.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
